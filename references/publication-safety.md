# 公开发布与隐私安全

## 公开包不得包含

- 真实案件材料、真实案件 Manifest、真实文书、OCR 文本或截图；
- 姓名、手机号、身份证号、账号、案号、公司内部数据或真实文件名；
- 本机绝对路径、UNC 路径、用户名、凭据、日志、缓存、Office profile、锁文件和系统元数据；检查范围包括文件内容、文件名和可读二进制 metadata；
- 私有测试输出、渲染中间物、用户拒绝公开的信息。

内部覆盖矩阵会包含请求说明、法律要件、claim 和材料编号，属于案件工作文件。公开发布 Skill 时只能保留全合成矩阵夹具；真实案件生成的 `*.coverage-matrix.json` 不得进入源码包、安装包或社交媒体演示附件。

公开示例必须是全合成材料，或在隔离副本上完成不可逆脱敏并由人工逐页复核。不能把演示视频称为案件原始载体；社交媒体副本只能标记为 public_demo_copy 或 social_media_copy。

## 发布前检查

    python scripts/package_check.py <skill-root>

项目维护者还应通过 --forbidden-token 加入本次私有测试中的案件名、当事人名和项目专有词。检查通过只表示包结构和静态隐私扫描通过，不证明材料真实性、法律责任或全平台运行结果。

上传 RedSkill 时，只打包运行时目录：`SKILL.md`、`VERSION`、`LICENSE`、`agents/`、`assets/`、`references/`、`scripts/`；`evals/` 只保留在 GitHub 源码/评测包，不进入安装包。ZIP 内应只有一个顶层 `build-evidence-bundle/` 目录并直接包含 `SKILL.md`。单文件不得超过 10MB，解压后总大小不得超过 30MB；`package_check.py` 会执行这两项大小门禁。

## 本地处理承诺

运行脚本不上传案件材料、不自动联网、不安装外部工具、不修改原始材料。输出默认拒绝覆盖，Office 转换只写入全新隔离目录；宏、外链、隐藏内容、备注/批注或嵌入对象等高风险包不得自动转换。发布包中的合成夹具不得含可关联真实案件的文本或媒体。
