# 证据材料筛选、填充与质检规则

## 一、原件优先，截图用于阅卷

Word 内嵌图片是阅卷副本，不替代原始证据。始终保留原手机、原应用聊天、录屏、转账账单、纸质原件和未经压缩的图片。

## 二、录屏截帧

需要从录屏截帧时，至少覆盖：

1. 联系人或群资料页；
2. 关键聊天前后各一段上下文；
3. 金额、日期、收付款主体同时可见的画面；
4. 催告、承认、结算或签字；
5. 能显示连续滚动过程的原录屏文件。

截帧文件名推荐：

`组号-序号-录屏名-时间戳-待证事实.png`

同时保留索引：

`录屏文件名｜起止时间｜截帧文件｜关键内容｜对应清单编号`

不得只保留截帧后删除录屏。

## 三、金额四口径

所有款项分别记录：

- 订单额；
- 二维码/申请额；
- 实际支付额；
- 对方认可或结算额。

另列：

- 已清偿金额；
- 未清偿金额；
- 计算公式；
- 证据来源。

任一口径不一致，正式版生成前必须由用户确认。表载合计与分项合计不一致时，同时展示两者和差额，不得擅自挑选。

## 四、日期核对

日期优先级：

1. 原始电子数据完整时间；
2. 转账回单/账单详情；
3. 书证记载日期；
4. 截图界面日期；
5. 文件创建/修改时间；
6. 文件名和当事人口述。

低优先级来源不得覆盖高优先级来源。聊天只显示“周一”“3月5日”时，需从上下文或原始数据补足年份。

## 五、图片选择与去重

- 完全相同哈希只保留一份；
- 同一聊天内容的不同裁切版，优先保留主体、时间和上下文更完整者；
- 同一事实存在“聊天截图＋账单详情”，两者均保留，因为证明功能不同；
- 模糊图片不得为节省页数而放大到失真；
- 对含身份证号、手机号、银行卡号的材料，依提交目的决定是否制作脱敏副本，原件另行保留。

## 六、分页和缩放

- 清单表格结束后插入分页符；
- 每张材料独立成页、独立成段；
- 等比例缩放到版心内，绝不裁切；
- 纵向长截图优先受页面高度限制；
- 横向执照、表格优先受页面宽度限制；
- 图片居中，段前段后为 0；
- 每组“页数”等于该组实际嵌入图片页数。

若一张图片缩放后文字不可辨，应拆分为“全貌页＋局部放大页”，两页均注明来自同一原件，并计入页数。

## 七、填充前检查

- [ ] 清单顺序已由用户确认或有明确请求权结构；
- [ ] 每张图片已归入唯一主组；
- [ ] 主体身份有资料页或其他补强；
- [ ] 关键聊天含上下文；
- [ ] 转账显示时间、金额、对方和状态；
- [ ] 结算单有全貌及签字细节；
- [ ] 金额、日期、已清偿状态无冲突；
- [ ] 证明对象未超出材料内容；
- [ ] 原始载体仍在。

## 八、填充后检查

- [ ] 表格行数＝证据组数＋表头；
- [ ] 图片数＝各组材料数之和；
- [ ] 页数字段＝各组材料数；
- [ ] 表格第N项后首先出现该组第1张图；
- [ ] 组间无串页、漏页、重复页；
- [ ] 第一张、最后一张和每个组边界已抽查；
- [ ] DOCX 可打开并可编辑；
- [ ] 有条件时完成页面渲染检查。
