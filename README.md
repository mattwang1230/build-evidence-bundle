正文
做诉讼材料时，最耗时间的往往不是写“证据清单”四个字，而是后面的细活：

聊天截图怎么分组？
录屏截哪几帧？
证明对象会不会写过头？
几十张图片怎样按清单顺序塞进 Word？
金额和日期对不上时，谁来提醒？

我把自己实际制作“证据清单＋证据材料卷”的方法，整理成了一个可复用的 Codex Skill：build-evidence-bundle。⚖️

它会先盘点案件材料，再按照：

主体身份—关系建立—事实发生—履行付款—催告—承认—结算签字

建立证据链顺序。

之后生成一份可编辑 Word：

✅ 首页是五列表格
✅ 后面按清单编号逐页插入证据
✅ 图片等比例缩放，不裁切
✅ 自动回填每组页数
✅ 保留录屏、原始聊天等电子证据要求
✅ 金额、日期、主体或清偿状态冲突时，阻止生成正式版

我最想保留的不是“一键生成”，而是这条底线：

现有截图证明不了的事实，不能靠文案补出来。

这次也重新测了可用性：

相对路径可以按清单文件所在目录解析；
48份、约31.5MB材料盘点约0.12秒；
重复盘点不会把盘点结果自己算进去；
依赖和安装命令已经补齐；
发布包不含真实案件姓名、公司名、金额和本机路径。
